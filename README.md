# Yanye Tang

Applied Machine learning developer in Halifax, NS.

## Projects

- **[AcousticWise](https://github.com/yanyetang/acousticwise)**: classifies vessel type from underwater sound. A log-mel CNN beats an MFCC baseline on vessels never seen in training, and runs in a local Streamlit app. *Python, PyTorch, Streamlit.*
- **[nexus-chat-api](https://github.com/yanyetang/nexus-chat-api)**: evaluates and tunes a RAG chatbot. DeepEval scores its answers with an LLM judge in CI, and DSPy (MIPROv2) uses those scores to find a better system prompt offline. The chatbot is a FastAPI backend that searches a supplier catalog (pgvector, Cohere reranking). *Python, DeepEval, DSPy, FastAPI.*
